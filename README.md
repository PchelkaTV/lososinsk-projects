# Единый реестр муниципальных проектов города Лососинска

Официальный каталог муниципальных строительных заданий. В реестре 61 объект: описание, перечень работ, исполнители, стадии реализации, фотографии и очередность строительства.

## Структура
- `index.html` — публичный портал
- `projects.json` — каталог проектов, категорий и зависимостей
- `progress.json` — назначенные исполнители, статусы и степень готовности
- `images/` — каталог фотографий объектов; список имён см. в `images/README.md`

Панель администрации (`admin.html`) в этом репозитории отсутствует и публиковаться не должна.

## Обновление статусов
Измените данные в локальной панели администрации, экспортируйте новый `progress.json` и замените его в репозитории. Сайт будет читать опубликованный JSON при загрузке.

## GitHub Pages
В настройках репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку **main**, папку **/(root)**, затем **Save**. Адрес сайта после активации: https://pchelkatv.github.io/lososinsk-projects/
